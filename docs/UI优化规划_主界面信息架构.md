# UI 优化规划（主界面信息架构重构）

> 依据：用户提供的当前界面截图
> 状态：**规划阶段，尚未修改代码**（等开发命令）
> 视角：UI / 信息架构

---

## 一、问题诊断

### 🔴 P1 状态与操作混淆（严重）

截图中这一块：

```
[✓ 当前批次已完成]  [✨ 重新生成（新批次 6 张）]  [■ 停止]
   ↑ 蓝色实心           ↑ 蓝色实心                ↑ 白色禁用
```

**问题**：
- **「当前批次已完成」是状态，却长得和主操作按钮一模一样**
- 两个蓝色实心按钮并排 → 用户**不知道该点哪个**
- 它**点不动**，但视觉上完全可点 → 点了没反应，产生挫败

**UI 原则**：状态用 chip / badge（无边框、无 hover），操作才用 button（有三态）。

---

### 🔴 P2 合规警示被淹没（严重 · 有业务风险）

AGENTS.md 硬性要求：

> 缺少照片时只能输出并明确标记为**"模拟门店背景"**。不要把模拟图描述为实拍图。

而当前「模拟门店背景」只是**一行 11px 灰字**中的一段，夹在「已完成 6/6 张效果图 ·」和「· 真实感 V3」之间。

**风险**：用户（尤其客服/运营）**可能把模拟图当成实拍图发给客户**。

**要求**：合规信息必须**有独立视觉通道**（颜色 + 图标 + 位置），不能混在描述句里。

---

### 🟠 P3 技术细节占据黄金位置

```
输出 E:\1_Software\6_AI工具\deepseek\2_开发\图片生成\output\batch_20260920_144539_qwen_qwen-image-3.0
```

**问题**：
- 绝对路径**长到换行**，把元数据行挤成两行、破坏对齐
- **普通用户不关心绝对路径**（设计师只关心图，客服只关心能不能导出）
- 它是**排障信息**，应该"需要时能看到"，而不是"永远占位"

**改法**：缩短为 `批次 20260920_144539`，完整路径放**悬停 tooltip + 点击复制**。

---

### 🟠 P4 进度条空间利用率低

```
████████████████████████████████ 100%
                                                      6 / 6 张
100%
```

**问题**：
- 进度条占**整行宽度**，但 100% 时左侧没有信息 → 大片空白
- **「100%」在最左上方**，「6 / 6 张」在最右侧 → **同一件事的两个数字被拉开 1400px**
- 完成后进度条**不再需要这么大面积**

**改法**：`6 / 6 张` 做大放左（主数值），进度条缩为中等宽度居中，百分比并入数字区。

---

### 🟡 P5 信息重复

| 位置 | 文案 |
|------|------|
| 视图栏左 | 「已完成 6 / 6 张效果图」 |
| 视图栏右 | 「✓ 效果图已齐全」 |

**同一个事实说了两遍**，还分别占了最左和最右，把中间的有效信息挤掉。

---

### 🟡 P6 三个维度混在一行

视图栏这一行同时承载：

```
[生成图][效果图]   已完成 6/6 张效果图 · 模拟门店背景 · 真实感 V3
   ↑ 视图切换         ↑ 完成度      ↑ 合规警示    ↑ 质量等级
```

**四个不同维度、不同读者**：
- 视图切换 → 所有人高频
- 完成度 → 所有人
- **模拟背景 → 合规（必须醒目）**
- 真实感等级 → 懂行的设计师

混在一行 → **谁都不突出**。

---

### 🟡 P7 字号层次不足

| 元素 | 当前 | 问题 |
|------|------|------|
| 配置胶囊 | ~12px | 与状态文字同权 |
| 元数据 | ~11px | 中文 11px 可读性差 |
| 进度百分比 | 大 | 权重远高于其它 |

**缺少中间层次**，导致「重要的不够大、次要的不够小」。

---

### 🟡 P8 顶栏元素过密

一行 6 个元素（配置胶囊 + 状态 + 2 操作 + 停止 + 账号区），
已靠 `@media` 在窄屏隐藏部分内容 —— 这是**打补丁**，不是解决密度问题。

## 二、优化原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **状态 ≠ 操作** | 状态用 chip（无边框、无 hover）；操作才用 button |
| 2 | **合规信息独立通道** | 颜色 + 图标 + 固定位置，不混在描述句 |
| 3 | **技术细节渐进披露** | 默认短，悬停/点击给全，一键复制 |
| 4 | **一个事实只说一次** | 去重，把位置让给有效信息 |
| 5 | **按维度分区** | 同维度信息聚在一起，不同维度物理分隔 |
| 6 | **主数值放大** | 用户最关心的数字（6/6）做视觉锚点 |
| 7 | **字号三级制** | 主数值 20~24px / 正文 13px / 细节 11.5px + 足够对比度 |
| 8 | **不隐藏重要信息** | 优化是"重新组织"，不是"删掉" |

## 三、改造方案

### 3.1 顶栏：状态归状态，操作归操作

**改前**
```
[◈] AI生图平台   [●阿里云百炼·qwen-image-3.0·1024x1024·试跑6张] [✓当前批次已完成] [✨重新生成(新批次6张)] [■停止]  系统管理 🏠 管理员 ⚙
```

**改后**
```
[◈] AI生图平台          阿里云百炼 · qwen-image-3.0 · 1024² · 6 张        [✨ 重新生成]   [■ 停止]     系统管理▾  🏠  管理员▾  ⚙
    门店玻璃贴纸智能设计平台   ● 已完成                                     主操作        禁用/次操作
```

**改动点**：
| 元素 | 改法 | 理由 |
|------|------|------|
| 配置胶囊 | **去掉胶囊背景**，改纯文字 + `·` 分隔 | 它是"背景信息"，不该抢视觉 |
| 「当前批次已完成」 | 改为 **`● 已完成` 状态点**（绿色小圆 + 文字） | 状态不是按钮 |
| 「重新生成（新批次 6 张）」 | 保留主按钮，文案缩为 **「✨ 重新生成」** | 数量已在配置区显示，避免重复 |
| 「停止」 | 保持按钮，但明确 **disabled 样式**（降透明度 + `cursor: not-allowed`） | 可点/不可点要一眼分辨 |

---

### 3.2 状态栏：重构为「数值区 + 进度区 + 徽章区」

**改前**
```
████████████████████████████ 100%
                                                          6 / 6 张
        服务商 阿里云百炼 · 模型 qwen-image-3.0 · 并发 2（20 RPM；安全调度 16 RPM）· 批次 批次_2026… · 输出 E:\...\output\batch_2026…
```

**改后**
```
┌──────────────────────────────────────────────────────────────────────────────────┐
│   6 / 6           ████████████████████████████████  100%        进行中 · 12 分钟   │
│    张                                                                             │
│                                                                                   │
│   ⚠️ 模拟门店背景    真实感 V3        批次 20260920_144539 ⧉     并发 2 · 20 RPM   │
└──────────────────────────────────────────────────────────────────────────────────┘
     ↑ 合规徽章（琥珀）   ↑ 质量徽章      ↑ 可复制             ↑ 技术参数（弱化）
```

**改动点**：
| 元素 | 改法 |
|------|------|
| `6 / 6 张` | **放大到 22px**，置于最左（视觉锚点） |
| 进度条 | 改为**弹性宽度**（不再占整行），100% 时收窄 |
| 百分比 | 紧贴进度条右侧 |
| **模拟门店背景** | **琥珀色徽章**（`⚠️` + 底色 + 深色文字），**固定在最左** |
| 真实感 V3 | 蓝色徽章 |
| 批次号 | **缩短**为 `20260920_144539` + `⧉` 复制按钮 |
| 输出路径 | **移除**（放悬停 tooltip + 点批次号复制） |
| 并发/RPM | 弱化到最右，11.5px |

### 3.3 视图栏：去重 + 标签带数量

**改前**
```
查看  [生成图] [效果图]     已完成 6 / 6 张效果图 · 模拟门店背景 · 真实感 V3          ✓ 效果图已齐全
```

**改后**
```
[生成图 · 6]  [效果图 · 6]                                          🪟 补齐效果图
```

**改动点**：
| 元素 | 改法 |
|------|------|
| "查看" label | **删除**（分段控件的形态已表达语义） |
| 标签页 | **带数量**：`生成图 · 6` / `效果图 · 6` |
| 三合一描述句 | **拆分**：合规+质量徽章移到状态栏；完成度并入标签数量 |
| "✓ 效果图已齐全" | **删除**（与「效果图 · 6」重复） |

## 六、已确认的决策（2026-09-20）

| # | 问题 | **决策** |
|---|------|---------|
| **Q1** | 「模拟门店背景」徽章位置 | ✅ **状态栏左侧** —— 琥珀色底 + `⚠️` 图标，置于状态栏第二行最左 |
| **Q2** | 输出路径处理 | ✅ **删除显示** —— 只显示 `批次 20260920_144539`，旁边 `⧉` 一键复制完整路径 |
| **Q3** | 运行时进度条动效 | ✅ **加流光动画** —— 区别于已完成状态（`prefers-reduced-motion` 下自动关闭） |

### 决策带来的连带调整

**Q1 → 状态栏左侧**
- 状态栏第二行结构定为：`[⚠️ 模拟门店背景] [真实感 V3] … [批次号 ⧉] [并发参数]`
- 视图栏（行 3）**不再出现**合规/质量徽章，避免重复
- 徽章加 `role="status"` 语义，屏幕阅读器可读

**Q2 → 删除路径显示**
- 移除 `app.js` 中 `· 输出 <b>${c.output_root}</b>` 的拼接
- 完整路径通过两个入口可达：
  1. 悬停批次号 → `title` 显示完整路径
  2. 点击 `⧉` → 复制到剪贴板 + Toast 提示
- **信息不丢失**，只是改变呈现方式

**Q3 → 流光动画**
- `.progress.running .bar::after` 用 `linear-gradient` 扫光
- **仅 `running === true` 时启用**
- 遵守 `@media (prefers-reduced-motion: reduce) { animation: none }`
