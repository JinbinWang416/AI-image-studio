## 调用建议

- 一次最多 3 张，分两批：先 1/2/3，再 4/5/6，便于逐张质检。
- 参数建议：`aspect_ratio: 1:1`、`output_name` 用 `jingdiantie-01` ~ `jingdiantie-06`。
- 若某张中文出错字或边缘被裁，用原提示词 `force: true` 重出该张，不要重出全部。

## 本次故障记录

- 现象：`generate_image` 全部调用返回 `Error: enhancePrompt is not defined`，与提示词内容无关（工具内部编码错误）。
- 次生现象：连续 3 次失败后触发 `Generation loop limit reached (3/3 consecutive generations)`，该计数器为会话级，用户在会话内确认后未清零。
- 结论：换新会话重开即可重置计数器；若新会话仍报 `enhancePrompt is not defined`，则需排查图像服务插件与 provider 配置。
