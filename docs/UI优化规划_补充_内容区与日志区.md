## 一、新截图暴露的 6 个新问题

### 🔴 P9 日志区空占近半屏（最严重的空间浪费）

截图实测比例（总高 916px）：

```
y=  0 ~ 250   顶栏 + 状态栏 + 视图栏
y=250 ~ 510   图片区（实际内容，仅 2 行图）
y=510 ~ 916   运行日志区  ← 约 406px，占 44% 屏高
```

**而这 406px 里什么都没有** —— 纯黑空白。

**后果**：
- 用户每次进来都要**滚过大片黑区**
- 真正重要的图被挤到上半屏
- 视觉上像"页面坏了"

**根因**：日志区用了固定高度（`min-height` 或 `height`），不随内容伸缩。

---

### 🔴 P10 日志区深色与整体主题断裂

| 区域 | 背景 |
|------|------|
| 顶栏 / 状态栏 / 视图栏 / 卡片 | 白 / 浅灰 |
| **运行日志** | **纯黑蓝 `#0f172a`** |

**问题**：
- 视觉上像"另一个应用嵌进来了"
- 深色区在浅色页面里**视觉权重最大** → 用户第一眼看到的是**没内容的黑块**，而不是图

**改法**：改为**浅色 + 等宽字体**，或保留深色但**默认折叠**（两者结合最好）。

---

### 🟠 P11 图片卡片缺少必要标识

截图中每张效果图：
- **右下角一个绿色小圆点** —— 语义不明（已生成？已选中？已质检？）
- **没有序号**（用户无法说"第 3 张要重做"）
- **没有文件名**
- 无 hover 提示

**后果**：沟通成本高（"左边那个第二个" vs "第 3 张"）。

---

### 🟠 P12 门店卡片右侧大片空白

截图里只选了 1 个门店：

```
┌──────────────┐
│ 01 房屋中介门店 │  ← 卡片占左侧 ~31%
│ [图][图][图]   │
│ [图][图][图]   │
└──────────────┘
                    ← 右侧 ~69% 全空
```

**问题**：单店/少量门店时，图片被压在窄列里，**每张只有约 90px 宽**，看不清细节。

**改法**：网格**自适应列宽** —— 门店少时卡片变宽、图片变大（`auto-fill` + `minmax`）。

---

### 🟡 P13 图片网格间距不均、缺少圆角

- 水平间距看起来**大于**垂直间距
- 图片**四角方正**，与卡片圆角不协调

---

### 🟡 P14 模拟背景的视觉强度与画面内容不匹配

截图里 6 张效果图是**明显的暖橘黄影调**（模拟生成的玻璃反射），一眼能看出不是实拍。

**但界面提示只有 11px 灰字**「模拟门店背景」。

**矛盾**：画面"很假"，提示"很弱" → 用户可能直接发出去。

**改法**（三处强化）：
1. 状态栏**琥珀徽章**（原 Q1 决策）
2. 图片**左下角小角标**「模拟」
3. 卡片头**背景来源标签**

## 三、完整方案

### 3.1 整体结构（改前 5 段 → 改后 5 段，但空间分配合理）

**改前**
```
┌─────────────────────────────────────────┐
│ 顶栏（6 元素挤一行）                       │  ~56px
├─────────────────────────────────────────┤
│ 进度条整行 + 6/6 张在右                    │  ~50px
│ 元数据行（路径换行成 2 行）                 │  ~48px
├─────────────────────────────────────────┤
│ 视图栏（4 维度混一行）                     │  ~40px
├─────────────────────────────────────────┤
│ 图片区（卡片只占 1/3 宽）                   │ ~260px
├─────────────────────────────────────────┤
│ 运行日志（空黑块）                          │ ~406px  ← 44%
└─────────────────────────────────────────┘
```

**改后**
```
┌─────────────────────────────────────────┐
│ 顶栏：品牌 | 配置·状态点 | 操作 | 账号      │  ~56px
├─────────────────────────────────────────┤
│ 6/6  ████████ 100%     进行中·12分钟       │  ~46px
│ ⚠️模拟门店背景  真实感V3   批次… ⧉  并发2   │  ~34px
├─────────────────────────────────────────┤
│ [生成图·6] [效果图·6]          [补齐效果图] │  ~40px
├─────────────────────────────────────────┤
│ ① 房屋中介门店              [☑ 完成]       │
│ ┌────┐┌────┐┌────┐┌────┐                 │
│ │ 1  ││ 2  ││ 3  ││ 4  │  ← 自适应列数      │  弹性
│ └────┘└────┘└────┘└────┘                 │  (占满剩余)
│ ┌────┐┌────┐                              │
│ │ 5  ││ 6  │                              │
│ └────┘└────┘                              │
├─────────────────────────────────────────┤
│ ▸ 运行日志（无内容时收起为一行）    [清空]   │  ~36px  ← 从 406px 降到 36px
└─────────────────────────────────────────┘
```

**空间释放**：日志区 **406px → 36px**，全部让给图片区。

### 3.2 日志区方案（P9 + P10）

| 项 | 改法 |
|----|------|
| **默认状态** | **收起**，只显示一行折头：`▸ 运行日志 (0)` |
| **有内容时** | 显示条数；**有 error 时自动展开**并高亮 |
| **展开高度** | `max-height: 30vh` + 内部滚动（不挤占内容区） |
| **配色** | 改**浅色**（`#f8fafc` 底 + 深灰字），保留等宽字体 |
| **记忆** | 用户手动展开/收起的选择存 `localStorage` |
| **清空按钮** | 保留，但仅在展开时显示 |

**效果**：不打断浏览图片，需要时一键展开。

### 3.3 图片卡片方案（P11 + P13 + P14）

**改前**
```
┌──────────┐
│  [图片]   │
│        ● │  ← 绿点语义不明
└──────────┘
```

**改后**
```
┌──────────┐
│ 1      ✓ │  ← 左上序号 + 右上状态
│  [图片]   │
│ 模拟      │  ← 左下角标（模拟背景时显示）
└──────────┘
   悬停：文件名 + [查看大图] [重做这张]
```

**要素**：
| 位置 | 内容 | 说明 |
|------|------|------|
| 左上 | **序号** `1`~`6` | `001` 补零便于排序沟通 |
| 右上 | **状态角标** | ✓已生成 / ⏳生成中 / ✗失败（带色） |
| 左下 | **「模拟」角标** | 仅当背景为模拟时显示（琥珀色） |
| hover | 文件名 + 操作 | 渐进披露 |
| 圆角 | `8px` | 与卡片协调 |
| 间距 | **统一 `10px`** | 修 P13 |

### 3.4 门店卡片自适应（P12）

**改前**：固定 3 列窄卡（单店时右侧全空）

**改后**：
```css
.stores {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(320px, 1fr));
  gap: 16px;
}
.store-card .thumbs {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
  gap: 10px;
}
```

**效果**：
- 1 个门店 → 卡片**占满整行**，图片从 90px 变 **约 200px**
- 3+ 个门店 → 自动排成多列

## 六、风险与回滚

| 风险 | 缓解 | 回滚 |
|------|------|------|
| 日志区默认收起后用户找不到日志 | 折头显示条数；**有报错自动展开** | 改回默认展开 |

**审计声明**：全部改动限于 `app/web/static/`（HTML/CSS/JS），
**不触碰** 接口、`output/`、历史批次、`config/settings.json`。

## 七、已确认的决策（2026-09-20）

| # | 问题 | **决策** |
|---|------|---------|
| **Q4** | 日志区默认态 | ✅ **默认收起**（无内容时仅一行 36px）；**有 error 时自动展开**并高亮 |
| **Q5** | 日志区配色 | ✅ **改浅色** —— `#f8fafc` 底 + 深灰字，保留等宽字体；视觉不再断裂 |
| **Q6** | 图片序号格式 | ✅ **`1` ~ `6`**（不补零） |

### 决策落地细节

**Q4 → 默认收起 + 报错自动展开**

```javascript
// 展开条件（任一满足）
const shouldExpand =
  hasError ||                              // 出现 error 级别日志
  localStorage.getItem('logExpanded') === '1';   // 用户上次手动展开过
```

- 折头显示：`▸ 运行日志 (N)` —— N 为条数，有 error 时 N 用红色
- 用户手动展开/收起 → 写 `localStorage`，下次沿用
- **首次访问且无日志** → 收起（不打断浏览）

**Q5 → 改浅色**

```css
.logpanel {
  background: #f8fafc;
  border-top: 1px solid var(--border);
  color: #334155;
}
.logpanel .line.error { color: #b91c1c; background: #fef2f2; }
.logpanel .line.warn  { color: #b45309; }
```

保留 `ui-monospace, Consolas, monospace` 等宽字体（日志对齐仍然重要）。

**Q6 → 序号 `1`~`6`**

- 左上角 `12px` 圆角小徽章，半透明深色底 + 白字
- 悬停淡出（不遮挡画面）
- `aria-label="第 N 张"` 供屏幕阅读器
