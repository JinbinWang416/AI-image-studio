## 2. 「视觉特征」要点表（可执行参数化描述）

> 下列区间取自 20+ 张实际主图的目测统计，可直接作为合成工具的默认值。

### 2.1 构图与占比

| 参数 | 观测值 | 说明 |
|------|--------|------|
| 画幅 | 1:1 正方形，800×800 或 1500×1500 | 无一例外，电商主图标准 |
| 拍摄角度 | **正面平视（80%）** ＞ 斜侧 15°~25°（15%）＞ 特写（5%） | 正面平视是主流，因为要让文字正读 |
| 贴纸占玻璃宽度 | **约 55% ～ 85%**，中位数 ≈ 70% | 双开门时贴纸横跨两扇门，视觉上占整门宽 70% 左右 |
| 贴纸垂直位置 | 垂直居中，**略偏上**（垂直中心落在画面上 45%~50% 高度处） | 对应人眼视高，约离地 1.2~1.5 m |
| 贴纸占玻璃高度 | 45% ～ 75% | 单扇门方案贴纸更高更瘦；双扇门方案更宽更矮 |
| 贴纸与门框关系 | **绝不跨过门框/竖梃**，边界完整落在单扇玻璃内 | 双开门的竖梃会把贴纸一分为二，是刻意构图 |
| 四周留白 | 玻璃边缘留 **10% ～ 20%** 空玻璃 | 留白让玻璃质感（透光+反光）能被看见 |
| 贴纸与相机距离 | 贴纸靠近玻璃（0~2 cm），**不悬空** | 悬空会露馅 |

### 2.2 玻璃后面能看到什么

| 场景 | 背景内容 | 处理方式 |
|------|---------|---------|
| 厨房玻璃门（最常见） | 橱柜、油烟机、台面、水槽、暖光下照明 | 整体**统一高斯模糊**，模糊半径约为画面宽度的 1.5%~3%；暗部压暗 |
| 住宅窗户 | 逆光远景：城市天际线 / 雪山 / 森林 / 雪景 | 高亮过曝，贴纸呈现「半透明薄纱」感（模拟静电膜透光） |
| 浴室隔断 | 黑色艺术墙、毛巾架、洗手台，**清晰不虚化** | 背景全清晰，靠斜侧角度和实拍反光建立真实感 |
| 生活化前景 | 儿童后脑勺、抱枕、绿植、书堆、窗帘 | **前景锐利 + 中景窗户 + 远景虚化**，三层景深是「实拍感」的核心配方 |
| 画面内文字/Logo | 背景家电上出现过第三方品牌标识、台历数字等 | 仅作真实感锚点存在，本报告不复述具体品牌 |

### 2.3 光线与反光

| 项目 | 观测做法 |
|------|---------|
| 色温 | 室内场景 **3200~3800K 暖光**；窗户场景逆光 5000~6500K |
| 光源方向 | 顶部筒灯 / 橱柜下灯带 → 在玻璃上形成**横向线性光带** |
| 玻璃反光 | **约 60% 的合成图完全没有任何反光**（最大破绽）；真实拍摄图能看到贴膜棱纹上的高光线条、彩虹衍射、相机/环境虚影 |
| 贴纸自发光感 | 合成图的贴纸亮度往往**高于环境**，像自带背光——这是「贴上去」感的直接来源 |

### 2.4 厚度与边缘

| 项目 | 观测做法 |
|------|---------|
| 边缘阴影 | **所有合成效果图都没有贴纸边缘阴影、没有厚度、没有投影**——100% 纯平色块 |
| 纹理质感 | 只有真实拍摄的图能看出材料质感：浮雕棱纹、磨砂颗粒、黑磨砂的细微凹凸 |
| 剖面演示 | 实拍安装图里可见「透明保护膜层 + 磨砂静电膜层」双层的真实厚度 |
| 边界锐度 | 合成图贴纸边缘是**数学级锐利**的矢量边，真实贴纸边缘有 **0.5~2 px 的柔和过渡与轻微透光** |

## 3. 「合成图常见做法与破绽」清单

### 3.1 常见做法（卖家实际用的技巧）

1. **背景统一高斯模糊**：拿一张真实室内照片整体模糊，贴纸直接盖在最上层。
2. **门框遮挡法**：贴纸只放在单扇玻璃内，不与门框相交，从而不需要处理「贴纸翻过门框」的透视难题。
3. **暗角 + 压暗**：给背景加暗角，让贴纸的亮色更跳。
4. **暖光调色**：整体加暖色调，掩盖合成时的色温不匹配。
5. **底部信息条遮盖**：在画面下沿压一条红底白字的尺寸条，同时承担「遮盖合成瑕疵」的功能。
6. **多层景深合成**：前景放锐利道具（抱枕/绿植/人物背影），中景放窗户，远景放虚化风景——三层结构最容易骗过眼睛。
7. **逆光过曝处理**：窗户场景直接把背景拉到接近过曝，贴纸因此可以半透明，省掉精确抠图。
8. **手入镜**：实拍安装图里手部入镜，用「手」这种高可信度元素建立真实感锚点。

### 3.2 破绽（一眼看出是合成的信号）

| 破绽 | 具体表现 | 我们的工具该怎么修 |
|------|---------|------------------|
| **无玻璃反光** | 玻璃上一个反射都没有，看起来像塑料膜 | 给玻璃层叠加一层低透明度环境反射/线性高光 |
| **背景不该清晰却清晰** | 贴纸后有背景物体，但物体锐度与周围完全一致，没有透过贴纸的衰减 | 贴纸层应位于「背景模糊层」与「反射层」之间，且贴纸自身带轻微透光 |
| **贴纸过亮、自带发光** | 贴纸亮度高于环境光，像背光屏 | 用环境光亮度归一化贴纸亮度，加轻微暗部衰减 |
| **边缘数学级锐利、零厚度** | 放大后边缘 1px 内完成过渡，无任何柔和 | 边缘加 0.5~2px 羽化 + 极轻的外侧微阴影 |
| **透视/角度不匹配** | 斜侧角度拍摄的背景，贴纸却是正面正交摆放 | 贴纸必须做与玻璃同平面的单应透视变换 |
| **色温不统一** | 暖光环境里贴纸是冷白/纯色 | 贴纸整体按背景白平衡做色调映射 |
| **背景模糊方式单一** | 全图均匀模糊，没有景深梯度 | 用径向/线性渐变的模糊强度模拟景深 |
| **门框处穿帮** | 贴纸边缘与门框相交处没有遮挡关系 | 优先让贴纸避开框体，或做正确的遮挡遮罩 |
| **画面里出现不该有的锐利细节** | 合成图背景偶尔夹杂原始素材的品牌 logo、台历等 | 背景素材需做去标识处理 |

### 3.3 一条最重要的结论

> **真实卖家效果图的「自然感」并不来自贴纸抠得干净，而来自玻璃反光层与景深分层。**
> 所有看起来自然的样本，都有玻璃反射或明显的景深结构；所有看起来「贴上去」的样本，都是「背景模糊 + 贴纸最顶层」的两层结构。
> 建议我们的合成管线从 2 层改为 **4 层：背景（带景深模糊）→ 贴纸（带透光与亮度归一化）→ 玻璃反射/高光 → 前景暗角与色调统一**。
