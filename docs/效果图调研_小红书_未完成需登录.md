### 建议登录后优先测量的参数清单（供合成算法直接使用）

- 贴纸高度 / 画面高度 之比；贴纸宽度 / 玻璃门宽度 之比
- 相机与门面夹角（正面 0° / 斜侧 30–45° / 侧拍）
- 拍摄距离与门宽之比（整门入画 / 半门 / 特写）
- 贴纸区域亮度 vs 玻璃背景亮度差（顺光 / 逆光 分别测）
- 贴纸边缘是否有 1–3px 高光/暗边（厚度感）、下方是否见投影
- 气泡密度、直径分布；翘边位置（角部/边中）
- 玻璃反射内容分类（天空 / 对街建筑 / 拍摄者 / 树影）及反射覆盖率
- 玻璃后景：可见 / 半虚化 / 全虚化；店内灯光明暗
- 白天 vs 夜晚（店内开灯）贴纸对比度变化
